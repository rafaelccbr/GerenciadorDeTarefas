# Frontend

React 19, Vite e Tailwind CSS 4. Veja o README da raiz para configurar o Worker, o D1 e a autenticação.

- `npm run dev`: Vite em localhost:5173, com proxy de /api para localhost:8787.
- `npm run build`: gera dist/ para o Worker.
- `npm run lint`: ESLint.
- `npm run preview`: serve apenas os assets, sem API. Para testar login e tarefas, use o Worker na raiz com npm run dev.
